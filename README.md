# Fit Loop — version 2

An offline Samsung Android app for a four-day, three-week repeating fat-loss plan using rowing and free weights.

## Included

- Week 1 foundation, Week 2 progression, Week 3 recovery, then repeat.
- Full Body, Upper Body, Lower Body, and Core + Conditioning days.
- Guided preparation, rest, and cooldown timers with pause, skip, and +30 seconds.
- Conservative starter weights followed by learned recommendations for each exercise.
- Easy, Right, and Heavy feedback that adjusts the next working weight.
- Offline illustrated exercise and rowing guides.
- Fields for weights, repetitions, rowing distance, and notes.
- Weekly body-weight and optional waist measurement log.
- All personal data stays on the phone.

Health Connect import remains reserved for a later version. Rowing results can be entered from Samsung Health.
